# 🏫 Portal TK Mutiara Harapan (Smart School Kids)

Selamat datang di repositori resmi **Portal TK Mutiara Harapan**, sebuah aplikasi web berbasis *Smart School* yang dirancang untuk mendukung kegiatan administrasi, informasi, dan pembelajaran digital di lingkungan TK Mutiara Harapan.

---

## 🌟 Fitur Utama
* **Beranda Interaktif:** Informasi profil sekolah, sambutan, dan galeri kegiatan.
* **Portal Akademik & Data:** Pengelolaan data siswa, guru, dan informasi kelas.
* **Manajemen Kegiatan:** Jadwal harian dan pengumuman penting bagi guru serta orang tua murid.
* **Desain Responsif:** Nyaman diakses menggunakan perangkat komputer maupun *smartphone*.

---

## 📂 Struktur Berkas Repositori
Repositori ini terdiri dari file-file utama berikut[cite: 1]:
* `index.html` — Halaman utama/antarmuka (UI) website portal.
* `mutiara_website_app.js` — Logika aplikasi dan interaksi pengguna (*JavaScript*).
* `mutiara_website_data.js` — Penyimpanan data sementara atau kumpulan informasi sekolah.
* `mutiara_website_style.css` — Desain, tata letak, dan tema visual website (*CSS*).
